# Blinkit Sales Dashboard - Power BI

![Dashboard Preview](https://github.com/bhanusolanki45/Blinkit-Sales-Dashboard-PowerBI/blob/main/Blinkit.pdf)

## Project Overview
This is an interactive Power BI dashboard built to analyze Blinkit (India's leading quick-commerce grocery delivery platform) sales performance. The dashboard provides actionable insights into sales trends, outlet performance, item categories, fat content distribution, and customer ratings.

**Key Metrics Covered:**
- Total Sales: $1.20M
- Average Sales: $141
- Average Rating: 4
- Number of Items: 8523
- Outlet establishment trends, size, location, and type analysis
- Item type sales breakdown (Fruits & Vegetables, Snacks, Household, etc.)
- Fat content analysis (Low Fat vs Regular)

## Business Insights
- Highest performing item categories and outlet types
- Sales trends over time by outlet establishment year
- Impact of outlet size, location tier, and type on sales and ratings
- Fat content preferences across outlets

## Tools & Technologies
- **Microsoft Power BI Desktop** – for data modeling, DAX measures, and visualization
- Data cleaning and transformation using Power Query

## How to Use
1. Download the `Blinkit Sales Dashboard.pbix` file
2. Open it in Power BI Desktop (free download from Microsoft)
3. Interact with filters (Outlet Location Type, Outlet Size, Item Type) to explore the data
4. All data is embedded in the .pbix file – no external connections needed

## Data Source
The dataset used is a public/sample grocery sales dataset representing Blinkit operations (commonly used in data analytics tutorials and portfolios).
